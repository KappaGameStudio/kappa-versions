# Kappa — téléchargements

**Kappa** est un jeu de tir tactique en ligne, 5 contre 5, développé et édité par Kappa Studio Paris.
Site officiel : https://kappastudio.xyz

## Télécharger le jeu (Windows)

1. Ouvrez la **[dernière version](https://github.com/KappaGameStudio/kappa-versions/releases/latest)**
   et téléchargez le fichier `Kappa_….zip` (environ 1,1 Go).
2. Décompressez-le dans un dossier (par exemple `Documents\Kappa`), puis lancez `Kappa.exe`.
3. Si Windows affiche « Windows a protégé votre ordinateur » : *Informations complémentaires* → *Exécuter quand même*.
4. Pour jouer en ligne, connectez-vous avec un compte Epic Games (gratuit).

Les mises à jour s'installent ensuite depuis le jeu : inutile de revenir ici.
Les fichiers `kappa_N.pck` des autres versions sont ces mises à jour : ils ne servent pas seuls.

## Download (English)

Open the [latest release](https://github.com/KappaGameStudio/kappa-versions/releases/latest), download `Kappa_….zip`,
extract it and run `Kappa.exe`. Updates are installed from the game.
